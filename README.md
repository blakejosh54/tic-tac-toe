# ❌⭕ TicTacToe HQ

A modern TicTacToe game built with **React** and **Vite**.

This project starts as a simple 3x3 game, but it was built with **clean state management**, **scalable UI structure**, and extra features like **Undo Move** and **Play vs AI**.

---

## ✨ Features

### Core Gameplay
- 3x3 TicTacToe board
- Players alternate turns between **X** and **O**
- Prevents overwriting filled cells
- Detects:
  - row wins
  - column wins
  - diagonal wins
  - draws
- Displays winner/draw state clearly
- Highlights winning cells

### State Management
- Built with **React Context + `useReducer`**
- Centralized game logic
- Readable reducer actions
- Move history tracking for Undo
- Shared game state across components

### Extra Features
- 🔁 **Undo Move**
- 🤖 **Play vs AI**
- 🌓 **Light / Dark theme toggle**
- 🏆 Score tracking between rounds
- 📱 Responsive design for mobile and desktop
- 🎭 Player avatars
